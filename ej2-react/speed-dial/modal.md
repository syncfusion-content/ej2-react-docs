# Modal in React Speed Dial

Enable modal mode for the React Speed Dial component by setting the [`modal`](https://ej2.syncfusion.com/react/documentation/api/speed-dial#modal) property to `true`. When modal is enabled, a semi-transparent overlay appears behind the popup, dimming the background and preventing user interaction with page content outside the React Speed Dial menu. This is useful for creating focused user experiences or guiding users through required actions.
