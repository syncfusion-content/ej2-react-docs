# How to reset an image in React Image Editor

The [`reset`](https://ej2.syncfusion.com/react/documentation/api/image-editor/index-default#reset) method restores the image to its original, unmodified state by undoing all changes (such as adjustments, annotations, or transformations); invoke `reset` when you want to discard edits and start over.
