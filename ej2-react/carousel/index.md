# Index in React Carousel component

The React **Carousel** component allows users to display images with content, links, etc., like a slide show. Typical uses of React Carousel include scrolling news headlines, featured articles on home pages, and image galleries.

## Key Features

* **Rendering** - The React Carousel component can be rendered based on the items collection and data binding.
* **Animation** - Supports animation effects for moving previous/next item of React Carousel.
* **Template Support** - The React Carousel component items and buttons can also be rendered with custom templates.
* **Keyboard Support** - By default, the React Carousel allows interaction with commands by using keyboard shortcuts.
* **Accessibility** - The React Carousel provides built-in compliance with the `WAI-ARIA` specifications and it is achieved through attributes.
