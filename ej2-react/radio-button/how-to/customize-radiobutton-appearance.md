# How to customize appearance in React Radio Button

Customize the React Radio Button's visual appearance by applying custom CSS rules through the [`cssClass`](https://ej2.syncfusion.com/react/documentation/api/radio-button/#cssclass) property. Define CSS classes targeting the React Radio Button element, then apply them to change styling attributes like background color, border color, and size.

Create semantic style variants (primary, success, warning, danger, info) by defining custom CSS classes that override the default React Radio Button colors and borders. This approach allows you to match your application's design system and provide visual feedback for different states or categories.
