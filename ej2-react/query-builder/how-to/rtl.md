# How to enable right to left in React Query Builder UI

Right-to-left (RTL) support enables the React Query Builder UI to adapt its layout and text direction for languages that read from right to left, such as Arabic, Farsi, and Urdu. This improves accessibility and user experience for these language communities. Enable RTL by setting the [`enableRtl`](https://ej2.syncfusion.com/react/documentation/api/query-builder#enablertl) property to `true` (default: `false`).
