# Data Binding in React Breadcrumb

## Items as tag directive

The React Breadcrumb contains `BreadcrumbItemsDirective` and `BreadcrumbItemDirective` tags to render items for the component. To bind items, use  `BreadcrumbItemsDirective` tag and `BreadcrumbItemDirective` tag to bind properties for React Breadcrumb items.

## Items based on current URL

The React Breadcrumb items can be generated from the current URL of the page, if the [`url`](https://ej2.syncfusion.com/react/documentation/api/breadcrumb#url) property is not provided or when the user does not specify the React Breadcrumb items using the `BreadcrumbItemDirective` tag.
