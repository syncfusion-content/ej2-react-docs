# Browser Support in React Data Grid

Syncfusion® React Data Grid component support modern browsers and rely on current web platform features.
The Data Grid is compatible with all common desktop and mobile browsers.

| Browser | Supported versions |
|---|---|
| Chrome | Latest |
| Firefox | Latest |
| Opera | Latest |
| Edge | 13+ |
| Internet Explorer (IE) | 11+ |
| Safari | 9+ |
| iOS Safari | 9+ |
| Android Browser / Chrome for Android | 4.4+ |
| Windows Mobile | IE 11+ |

For furthur details on browser compatibility, see the [Syncfusion React Browser](https://ej2.syncfusion.com/react/documentation/browser) documentation.
