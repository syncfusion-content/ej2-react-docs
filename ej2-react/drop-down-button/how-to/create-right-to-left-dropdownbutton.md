# How to enable RTL in React Dropdown Menu

The React Dropdown Menu component supports right-to-left (RTL) display for languages and locales that use RTL scripts. Enable RTL support by setting the [`enableRtl`](https://ej2.syncfusion.com/react/documentation/api/drop-down-button/#enablertl) property to `true`.
