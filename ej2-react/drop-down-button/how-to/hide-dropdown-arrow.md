# How to hide dropdown arrow in React Dropdown Menu

Remove the dropdown caret icon from the React Dropdown Menu by adding the `e-caret-hide` class using the [`cssClass`](https://ej2.syncfusion.com/react/documentation/api/drop-down-button/#cssclass) property. This is useful for creating icon-only buttons or buttons with custom styling where the caret is not needed.
