# How to disable in React Toggle Switch Button

Prevent user interaction with the React Toggle Switch Button component by setting the [`disabled`](https://ej2.syncfusion.com/react/documentation/api/switch/#disabled) property to `true`. Disabled React Toggle Switch Button appear grayed out and cannot be toggled, used for read-only states or when the option is temporarily unavailable.
