# How to enable RTL in React Toggle Switch Button

Enable right-to-left (RTL) layout support in the React Toggle Switch Button component by setting the [`enableRtl`](https://ej2.syncfusion.com/react/documentation/api/switch/#enablertl) property to `true`. RTL support mirrors the component layout and text direction, accommodating languages that read from right to left, such as Arabic, Hebrew, and Persian.
