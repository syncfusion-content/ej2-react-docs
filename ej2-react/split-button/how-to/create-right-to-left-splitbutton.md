# How to enable RTL in React Split Button

Enable right-to-left (RTL) layout support in the React Split Button component by setting the [`enableRtl`](https://ej2.syncfusion.com/react/documentation/api/split-button#enablertl) property to `true`. RTL support flips the component layout and text direction, making it suitable for languages that read from right to left, such as Arabic, Hebrew, and Persian.
