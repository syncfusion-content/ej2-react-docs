# Style and Appearance in React Menu

To modify the React Menu appearance, you need to override the default CSS of Menu component. Please find the list of CSS classes and its corresponding section in Menu component. Also, you have an option to create your own custom theme for the controls using our [`Theme Studio`](https://ej2.syncfusion.com/themestudio/?theme=material).

CSS Class | Purpose of Class
-----|-----
|.e-menu-wrapper|To customize the React menu wrapper
|.e-menu-wrapper.e-menu-popup|To customize the React menu popup wrapper
|.e-menu-wrapper ul .e-menu-item|To customize the React menu items
|.e-menu-wrapper.e-menu-popup .e-menu-item|To customize the React menu popup items
|.e-menu-wrapper ul .e-menu-item .e-caret|To customize the React menu items caret icon
